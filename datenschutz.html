2. Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt, einen Dienst von GitHub. Beim Aufruf der Website werden technisch erforderliche Daten verarbeitet. Dazu kann insbesondere die IP-Adresse gehören. GitHub gibt an, IP-Adressen von Besuchern von GitHub-Pages-Websites zu Sicherheitszwecken zu protokollieren und zu speichern. Die Verarbeitung erfolgt zur sicheren und technisch zuverlässigen Bereitstellung der Website.

Weitere Informationen zur Datenverarbeitung durch GitHub finden sich in der Datenschutzerklärung von GitHub.

Wenn Sie uns per E-Mail kontaktieren, verarbeiten wir die von Ihnen übermittelten Angaben zur Bearbeitung Ihrer Anfrage und für mögliche Anschlussfragen. In anderen Fällen erfolgt sie aufgrund unseres berechtigten Interesses an der Bearbeitung Ihrer Anfrage.

4. Projektanfrage / FormSubmit

Für die Projektanfrage nutzen wir den externen Formulardienst FormSubmit. Wenn Sie das Formular absenden, werden die von Ihnen eingegebenen Daten – beispielsweise Name, Unternehmen bzw. Verein, E-Mail-Adresse, optional Telefonnummer sowie Angaben und Wünsche zum Projekt – an FormSubmit übermittelt und zur Zustellung der Anfrage an uns verarbeitet.

Je nach technischer Ausgestaltung können außerdem technische Metadaten wie Browser-/Geräteinformationen, Referrer oder IP-bezogene Daten verarbeitet werden. Der Anbieter weist darauf hin, Formulardaten zur Bereitstellung des Dienstes zu verarbeiten. Dabei kann eine Verarbeitung außerhalb des Europäischen Wirtschaftsraums stattfinden. Bitte übermitteln Sie über das Formular keine besonders sensiblen Informationen, die für die Projektanfrage nicht erforderlich sind.

Die Verarbeitung erfolgt, soweit Ihre Anfrage auf einen möglichen Vertrag gerichtet ist, zur Durchführung vorvertraglicher Maßnahmen; im Übrigen auf Grundlage unseres berechtigten Interesses an einer effizienten Bearbeitung von Anfragen.
