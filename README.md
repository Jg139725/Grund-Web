# GRUND WEB

Erste Website-Version für GRUND WEB.

## GitHub Pages
1. Alle Dateien aus diesem Ordner in dein GitHub-Repository hochladen.
2. Repository → Settings → Pages.
3. Branch `main` und Ordner `/ (root)` auswählen.
4. Speichern.

## Vor Veröffentlichung ändern
- In `index.html` `DEINE-EMAIL@BEISPIEL.DE` durch deine echte Geschäfts-E-Mail ersetzen.
- Impressum und Datenschutz mit echten Seiten/Inhalten ergänzen.
- Projektbilder/Referenzen ergänzen.

Dateien:
- index.html
- style.css
